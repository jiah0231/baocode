# BaoCode 1.9.1+43

## 快捷提问和编辑

- 小窗继续贴在选区末尾，保持非模态、无标题和紧凑布局。
- 统一输入与回答区域的主题背景、边框、圆角和留白；模式按钮分组，发送和停止作为主要操作。
- 回答支持 Markdown，模型返回文本时立即逐段显示，不再等整条回答完成。
- 停止、关闭或发起新请求后，旧请求不能继续覆盖界面。超时和服务错误仍使用安全提示。
- 修改模式仍先预览，只有完整成功的结果才能替换原选区；取消或失败的半截结果不能应用。
- 保留单独选模型、上下文查看、附近上下文开关、复制、撤销以及源文本变化检查。

## 设计参考

只借鉴交互与层级，不复制代码或素材：

- [VS Code Inline Chat](https://code.visualstudio.com/docs/chat/inline-chat)：围绕可见选区的小型编辑入口。
- [Notion AI 官方设计说明](https://www.notion.com/blog/the-design-thinking-behind-notion-ai)：与原文分开的结果预览和显式接受。
- [Cursor 0.50 内联编辑更新（2025）](https://cursor.com/en-US/changelog/0-50)：紧凑输入与操作分层。这是历史设计参考，不代表当前 Cursor 的全部交互。

## 验证范围

本版本使用离线模拟端点验证增量输出、协议转换、取消、超时、错误、输出上限和编辑保护，并验证浅色/深色和小窗口布局。Windows 发布流程仍执行分析、回归测试、启动、关机重开和从 +42 升级检查。未在用户电脑上操作或验证其真实账号和供应商响应。
