# BaoCode 1.9.1+52

- Windows 任务栏右键菜单新增“新建窗口”，跟随软件语言显示，复用已有进程打开独立原生窗口。
- “新建窗口”命令和 Ctrl+Shift+N 在默认设置下也能真正多开；首次使用会启用独立窗口模式，已有项目移到自己的窗口，未保存编辑继续先确认，取消不会新建。
- 从任务栏冷启动时只打开所请求的新窗口，不恢复旧项目；连续新建、独立关闭和主窗口隐藏后的再次新建共用同一引擎及数据目录。
- 保留现有翻译、快捷提问及其他定制功能，继续使用专属签名更新通道，下载后由用户确认重启安装。
- Windows 策略可能禁用任务栏跳转列表；旧固定图标若未刷新，可取消固定后重新固定新版图标。
