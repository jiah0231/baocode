# 定制版 1.9.1+41

## 全局快捷提问与修改

- 在代码页面或 Agent 页面按 Ctrl+Alt+K（macOS 为 Cmd+Alt+K）打开小窗。可在快捷键设置中修改。
- 优先使用当前选中的代码或文字，默认附带少量附近内容。发送前可查看上下文，并关闭附近上下文；不会发送整个文件或会话。
- 在设置 → 模型中单独选择快捷提问模型，默认跟随辅助模型。显式选择的模型不可用时直接提示，不会偷偷换到其他提供商。
- 支持提问及修改两种模式。修改先预览，再由用户确认应用；代码和草稿变动后会拒绝覆盖旧位置。聊天历史等只读文字仅预览、复制。
- 小窗、主题切换和中文/英文界面保持一致。支持取消请求、Esc 关闭及 Ctrl/Cmd+Enter 发送。

## 保留与验证

- 基于定制版 1.9.1+40，保留官方上游合并、Windows 测试兼容修复和既有定制功能。
- 快捷提问测试与格式检查加入普通 Windows 构建和签名发布门禁，发布前仍需通过既有回归、安装包构建、启动和升级检查。
- 快捷键为 BaoCode 应用内全局快捷键，不是操作系统级热键。历史消息不会被改写，生成内容不会自动执行。
- CI 使用假模型验证交互与路由；未调用用户的真实模型账户。
