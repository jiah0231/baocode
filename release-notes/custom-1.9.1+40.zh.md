# 定制版 1.9.1+40

基于已发布的定制版 1.9.0+39，合并官方上游至
`e92b7cfb917718cad3fe519621be9d4767808cc0`（官方 v1.9.1 及其网站版本同步）。

## 本次新增

- 修复 Windows 关机、注销或安装器结束会话时的原生销毁崩溃。
- 跨历史分页的长回合和主动停止的回合可以正确折叠。
- 后台任务运行时，队列消息的“立即发送”正常生效。
- 内置核心的 Explore/Plan 遵循指定子代理模型，子代理显示正确供应商，同名模型更易区分。
- 项目支持按最近活动或手动排序；运行中和待处理代理不会隐藏在“显示更多”后。
- 修复消息编辑器可见性，增加 Git 日志详情布局切换、用量加载状态和单窗格关闭快捷键。

## 保留的定制功能

保留 +38 长对话重复扫描优化、+39 原生 Codex 模型菜单修复与旧会话路由、Ultra 能力传递、
NoteBoard 本地文档预览、Maple 字体和主题、浏览器面板、会话引用与专属签名更新通道。
SSH 代理访问本机的权限仍默认关闭，不扩大浏览器扩展权限，也不恢复已暂停的学习功能。

本次没有配对协议迁移。此更新不代表已复现或解决所有真实设备卡顿，也不代表已验证用户账户的 Ultra 推理。
Windows 构建、回归、独立安装目录中的 +39 升级、数据保留和会话结束测试通过后才会发布。
